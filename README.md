# MIS 310 Midterm Projects

The midterm includes a Tkinter employee records application and two versions of a CCSU information app. The employee application supports adding and editing records. The CCSU apps use pandas to read a CSV and display course-project information in a graphical interface.

## Run locally

```text
python -m pip install -r requirements.txt
python Project1_Employee_Records.py
python Project2_Part1_CCSU.py
python Project2_Part2_CCSU.py
```

Use a Python installation with Tkinter. Run one app at a time and keep the academic calendar CSV and logo beside the CCSU scripts. Part 2 adds views for the School of Business and the MIS department.
